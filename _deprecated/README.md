Тут лежить те, що в проєкті більше не використовується, але не видалене з історії:

- `print3d_deprecated/` — перший друкований набір: зварні вузли цілком, 1:7.
  Замінений набором окремих компонентів 1:5 (`print3d-parts/`).
- `print3d-parts_assembly/` — текстова інструкція складання набору 1:5 (`ASSEMBLY.md` / `.pdf`)
  з її генераторами й картинками. Замінена аркушами розкладки 1:1
  (`print3d-parts/sheets/SHEETS.pdf`), де є все те саме, але зручніше.
- `tools/` — разові інструменти, яких ніщо більше не викликає.

Шляхи всередині розраховані на старе розташування, тож як є скрипти не запустяться.
