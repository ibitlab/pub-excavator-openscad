# Публікація

## Ліцензія проєкту: її немає НАВМИСНО

Користувач свідомо відклав вибір власної ліцензії й публікує без неї. **Не створюй `LICENSE` у корені й не пропонуй додати** — тільки якщо він сам попросить.

Підстава рішення: надану ліцензію не можна відкликати для вже розданих копій, а додати її можна будь-коли пізніше. Тому «поки без ліцензії» — оборотний крок, а «під MIT» — ні.

`tools/viewer-wasm/LICENSE` — це **не** ліцензія проєкту, а текст GPL-2.0 для вшитого рушія. Не плутай і не переноси в корінь.

## GPL: що саме треба виконувати

Сторінка `tools/viewer-wasm/` вшиває сам OpenSCAD (≈11 МБ із ≈12 МБ збірки) під GPL-2.0-or-later. Обов'язкове, поки це так:

| Вимога | Де виконано |
|---|---|
| §1 — текст ліцензії поруч із бінарником | `tools/viewer-wasm/LICENSE`, копіюється в `dist/` кроком workflow |
| §3 — доступ до відповідних вихідних кодів | `THIRD-PARTY.md`: пакет `openscad-wasm-prebuilt@1.2.0`, рушій 2025.01.19, джерела `github.com/lorenzowritescode/openscad-wasm`, зібрані з `github.com/openscad` |
| Видимість для користувача сторінки | ключ `lic` у `src/i18n.js` — посилання внизу панелі, обома мовами |

Чому саме цей пакет: `openscad-wasm@0.0.4` не має ні файлу ліцензії, ні repository/homepage — походження встановити неможливо, §3 невиконанна. Офіційний `openscad/openscad-wasm` актуальних готових збірок не публікує (найновіша `2022.03.20`, до Manifold). Ідеальний варіант — зібрати з вихідників (Docker + gmake + Deno).

**Міняєш рушій — одночасно онови всі три рядки таблиці** й перевір, що новий пакет узагалі дозволяє встановити походження.

Вихід GPL-програми похідним твором не є: модель, STL, DXF і креслення GPL не заражені й належать проєкту.

## GitHub Pages

`.github/workflows/pages.yml`: push у `main` → `npm ci` → `npm test` → `npm run build` → копіювання `LICENSE` і `THIRD-PARTY.md` у `dist/` → `upload-pages-artifact` → `deploy-pages`. Увімкнути один раз: Settings → Pages → Source: **GitHub Actions**.

- `npm test` у конвеєрі стоїть навмисно: він валиться на попередженні рушія, порожній деталі, розходженні пози чи неперекладеному параметрі. Не прибирай його, щоб «швидше задеплоїти».
- Зібраний `dist/` у git **не кладеться**. Рушій у ньому байт-у-байт однаковий між збірками (модель лягає в чанк `index-*.js`, ≈600 КБ), тож теоретично репозиторій він не роздув би — але джерело правди лишається одне, і артефакт збирає CI.
- Actions на публічних репозиторіях безплатні.

## Перед пушем

1. **Нічого не пушити й не створювати remote без прямого слова користувача.** Репозиторій на GitHub він створює сам (Public, без README, `.gitignore` і ліцензії), далі дає адресу.
2. Перевір, що поза `temp/` немає особистого: ім'я, місто, назви постачальників і складів, локальні шляхи (`/Users/…`), скріншоти таблиць, номери замовлень. `.claude/settings.local.json` виключений — у ньому лишаються домени, які переглядалися.
3. Перевір **історію**, а не лише робочу теку: `git log --all -p | grep -niE "шаблон"`. Прибране з останнього коміту лишається в попередніх.
4. Двомовні документи мають однакову структуру: `README.md`/`README.uk.md`, `TECHNICAL.md`/`TECHNICAL.uk.md`, `QUICKSTART.md`/`QUICKSTART.uk.md`, `SAFETY.md`/`SAFETY.uk.md`, `THIRD-PARTY.md` (двомовний одним файлом). Правиш один — правь двійник у тому ж коміті.
5. Застереження про ШІ стоїть під H1 кожного README, у `VERSION.md`, у підвалі креслень і в панелі 3D-сторінки. Джерело формулювань — `SAFETY.md`.

## `.gitignore`

Git **не розуміє коментарів у кінці рядка з шаблоном**: `temp/   # чернетки` робить шаблоном увесь рядок, і тека не ігнорується. Коментар — тільки окремим рядком. Перевіряй не очима, а командою:
```
git check-ignore -v temp/x .claude/settings.local.json
```
