# Аналітика агентної роботи

```
python3 tools/agent_analytics.py [тека_проєкту_в_~/.claude/projects] > /tmp/agent_analytics.json
```
Без аргументу береться тека цього проєкту. Скрипт лише читає журнали (головна сесія `*.jsonl`, субагенти `*/subagents/workflows/*/agent-*.jsonl`, ролі — з `journal.jsonl` і `*.meta.json`) і нічого не пише поза stdout.

## Що рахується

- токени за категоріями: вихід (з міркуваннями), свіжий вхід (вхід без кешу + запис у кеш), читання кешу; дублікати одного повідомлення зливаються за `message.id`;
- хвилини: за годинником і «активні» (сума пауз між подіями < 5 хв — без нічних простоїв і очікування ліміту);
- виклики моделі та інструментів по кожному агенту, його мітка-роль і чи повернув він результат.

## Як оформити звіт

Структура: підсумкова таблиця (головний агент + кожен workflow), таблиця агентів із ролями, розділ «віддача і втрати» (скільки фактів/знахідок, що згоріло через ліміт або зупинку), і що ще варто міряти. Вартість у грошах рахуй лише якщо користувач дав прайс: у журналах його немає. Звіт — документ-джерело в `docs/agent-analytics-<РРРР-ММ-ДД>.md`, не у `versions/`.

Журнали лежать поза репозиторієм (`~/.claude/projects/…`) і містять усе, що писав користувач. **У звіт ідуть лише числа й ролі** — не цитуй вміст повідомлень і не вставляй шляхів із домашньої теки: `docs/` публічний.
