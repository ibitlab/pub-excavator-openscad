# Матеріали для публікацій

```
tools/media/make_media.sh [ТЕКА]        # за замовчуванням temp/media/ ; ≈ 5 хв; потрібні openscad, Chrome, ffmpeg, node
```
Дає `01_hero.png`, `02_poses.png`, `03_viewer_ui.png`, `04_bucket.png`, `05_drawings.png`, `06_clearances.png`, `07_dig_cycle.mp4` (квадрат, чиста сцена), `08_dig_cycle_ui.mp4` (уся сторінка з панеллю і робочою зоною). Окремі знімки — `tools/media/page_shot.mjs`, колажі — `tools/media/compose.py` (skill `browser-verify` — про граблі headless Chrome).

**Англійські варіанти скрипт не робить.** Він знімає СЕРВЕРНУ сторінку (`tools/viewer.py`), а вона лише українська. Для `03en_…`/`08en_…` бери WASM-сторінку з `?lang=en` і англійські підписи в опціях — інакше `page_shot.mjs` не знайде кнопку:
```
cd tools/viewer-wasm && npx vite build && npx vite preview --port 8797 --strictPort &
node tools/media/page_shot.mjs "http://127.0.0.1:8797/?lang=en" --out 03en_viewer_ui.png \
     --size 1600x1000 --dsf 2 --angles -20,100,55 --toggle "work envelope" --view "Side"
```
Відповідники: `Ізометрія`→`Isometric`, `Збоку`→`Side`, `Ззаду-збоку`→`Rear-side`, `робоча зона`→`work envelope`.

## Правила
- Усе кладеться в `temp/` — тека в `.gitignore` (і дубльовано в `.git/info/exclude`), бо `build_version.sh --commit` робить `git add -A`. Не комітити.
- **З `temp/` нічого не видаляй**, навіть проміжне (`raw/`, кадри відео). Скажи, що там лежить і скільки важить, — чистить користувач сам.
- Пози порівнюються лише в ОДНОМУ масштабі зі спільною лінією землі (`compose.py poses` відновлює масштаб із камери сторінки). Перевір це на готовому колажі очима: у V001 `02_poses.png` вийшов із двома різними лініями землі й порожнечею посередині — у пост він не годився, пози краще показує відео циклу копання.
- Кожне зображення відкрий і подивись перед тим, як віддавати: саме так знайшовся дефект ескізу труби.
- Текст: від першої особи користувача, двома мовами (uk, en); перші два рядки — гачок. Числа — лише з останньої зібраної версії; не стверджувати того, що не перевірено на залізі (метал не різаний, SpaceMouse без справжньої миші тощо); «N годин» — це проміжок між комітами, а не робочий час. Додай нотатку «що перевірити перед публікацією».
- **Абзац про ШІ обов'язковий у кожному публічному тексті**: модель, розрахунки й креслення згенеровано ШІ, інженер їх не перевіряв, метал не різаний, машина не збудована (джерело формулювань — `SAFETY.md`). ШІ-рев'ю не називати «незалежною інженерною експертизою» — це перевірка машиною.
- LinkedIn не змішує відео й фото в одному пості: або відео, або карусель.
